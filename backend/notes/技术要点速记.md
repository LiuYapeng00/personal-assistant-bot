# 技术要点速记

## ReAct Agent
- 循环模式：推理（thought）-> 行动（action）-> 观察（observation）
- 模型只输出 JSON，由后端解析成结构化决策
- 轮数上限 5，防止无限循环

## 工具注册表
- 注册表：工具名称 -> ToolSpec（函数 + 描述 + 参数校验）
- 统一入口 call()：校验参数 -> 执行 -> 异常转 Observation

## 容错设计（异常路径）
- 未知工具：返回"未知工具，可用工具：..."，不崩溃
- 参数错误：缺参 / 多余参 / 类型错，返回友好提示
- 工具内部异常（如除零）：统一捕获，转成可回传文本
- 解析失败：重试一次，再失败兜底回答"请换个问法"
- 核心原则：Agent 循环绝不因工具调用或解析而崩溃
