## Day3 FastAPI 路由

### uvicorn 启动方式
```bash
cd backend
uv run uvicorn app.main:app --reload --port 8000   # 开发模式（热重载）
uv run uvicorn app.main:app --port 8000              # 生产模式
```

### 常用调试命令
```bash
uv run pytest                              # 全部测试
uv run pytest tests/test_api.py -v         # 仅 API 测试
uv run ruff check src/ tests/              # 代码检查
```

### API 端点
- `GET /health` → `{"status": "ok"}`
- `POST /chat` → `{"message": "...", "history": []}` → `{"reply": "...", "trace": [...]}`

### 注意事项
- 空消息（`message: ""`）返回 422（Pydantic `min_length=1` 校验）
- CORS 允许 `http://localhost:5173`（Vite dev server）
- CLI 入口已迁移到 `cli.py`，可通过 `uv run python -m app.cli` 运行
