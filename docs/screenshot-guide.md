# 截图说明

启动项目后，按以下步骤截图：

## 截图 1: 聊天界面 (`screenshot-chat.png`)

1. 启动后端和前端
2. 打开浏览器访问 `http://localhost:5173`
3. 输入几个问题测试：
   - "你好"
   - "1 + 1 等于几"
   - "帮我搜索天气记录"
4. 截取完整聊天界面

## 截图 2: 工具调用卡片 (`screenshot-tool.png`)

1. 输入需要调用工具的问题：
   - "北京今天天气怎么样"（调用天气工具）
   - "计算 123 * 456"（调用计算器）
2. 截取工具调用折叠卡片展开后的效果

## 截图要求

- 包含完整的聊天界面（标题栏、消息列表、输入框）
- 工具调用卡片清晰可见
- 如有流式输出效果更好（逐字显示）

## 截图工具推荐

- Windows: Snip & Sketch (Win + Shift + S)
- Mac: Cmd + Shift + 4
- 浏览器插件: GoFullPage (整页截图)
